## Third-party APIs as proof-carrying service bindings

Every call returns `{ result, evidence }`. The evidence is a plain JSON bundle you can persist, audit, or hash.

```ts
const { result, evidence } = await env.STRIPE.charges.create({
  amount: 1000,
  currency: "usd",
  source: "tok_visa",
});

if (evidence.verdict === "fail") {
  return Response.json({ error: "verification failed", evidence }, { status: 502 });
}
```

## Architecture

```
 caller Worker        JSRPC        capa capability        HTTP        upstream API
┌─────────────┐    ───────▶    ┌────────────────┐    ───────▶    ┌────────────┐
│  env.STRIPE │               │ WorkerEntrypoint │               │  Stripe /  │
│   .charges  │◀──────────────│  fetchProof()    │◀──────────────│  GitLab /  │
│   .create() │   {result,    │  act + assert    │               │  Jira      │
└─────────────┘    evidence}  └────────────────┘               └────────────┘
```

`fetchProof` performs the upstream HTTP call (`act`), then runs generic + per-method assertions (`assert`). The verdict is the AND of every assertion.

## Quick start

### 1. Deploy a capability

Click a Deploy button below. Cloudflare clones the repo and deploys the Worker.

### 2. Set the API key

```bash
cd capabilities/stripe
wrangler secret put STRIPE_API_KEY
```

### 3. Bind and call

```jsonc
// wrangler.jsonc
{ "services": [
  { "binding": "STRIPE", "service": "capa-stripe", "entrypoint": "StripeCapability" }
]}
```

```ts
const { result, evidence } = await env.STRIPE.charges.create({
  amount: 1000, currency: "usd", source: "tok_visa",
});
```
