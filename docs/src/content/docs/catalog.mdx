Each capability is one Worker for one API. It exposes a typed method for every operation in the provider's OpenAPI spec. Deploy it, set its secret, and bind it from your Worker.

<CapabilityGrid stats planned />

## What every capability does the same way

| Property | Behavior |
|---|---|
| Public HTTP route | `fetch()` returns 404. Reach it through a service binding. |
| Upstream requests | One HTTP request per method call. |
| Return shape | `{ result, evidence }` |
| Credentials | A Worker secret, or per-call auth for multi-tenant callers. |
| Updates | A weekly job regenerates the binding when the spec changes. |

## Add an API

1. Run the [codegen CLI](/reference/#codegen-cli) against the provider's OpenAPI or Swagger spec.
2. Deploy the generated capability to your account.
3. To share it, follow the [contribution guide](https://github.com/acoyfellow/capa/blob/main/CONTRIBUTING.md), run `bun run check`, and open a pull request.

The catalog reads each `capabilities/<name>/capa.manifest.json` at build time. A merged capability appears here on the next deploy.
